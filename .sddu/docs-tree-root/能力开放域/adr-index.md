## 3. ADR 概述

能力开放域共 4 条 ADR，全部采纳（ACCEPTED）。核心决策方向：
1. **架构选型**（ADR-001）：单体 + 模块化，避免过度拆分；
2. **测试策略**（ADR-002）：第三方依赖 Mock 隔离；
3. **领域模型**（ADR-003）：权限资源抽象，统一 API/事件/回调治理；
4. **安全**（ADR-004）：事件/回调通道白名单。

注：数据开放平台与应用管理暂无独立 ADR 记录（应用管理处于 plan 阶段，数据开放平台搁置）。
