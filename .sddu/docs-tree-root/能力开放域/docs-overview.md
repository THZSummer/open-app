## 1. 业务全景

### 1.1 自身概述

| 属性 | 值 |
|------|-----|
| **类型** | 业务域（Domain） |
| **职责描述** | 统一能力开放底座：将平台内部业务能力（IM、云盘、邮件等）以 API/事件/回调三种标准形式开放给企业内三方平台，配套权限/审批/消费网关；并为开发者提供应用管理入口（能力订阅载体）；阶段 2 扩展数据开放通道 |
| **所属业务域** | open-app 开放平台 |
| **版本** | v1.0 |

### 1.2 子组件

| 组件 | 类型 | 描述 | 关系说明 |
|------|------|------|---------|
| **能力开放平台** | 业务对象 | 能力开放底座——分组管理、API/事件/回调注册治理、权限与审批、消费网关、Scope 用户授权 | 域核心；支撑数据开放平台；嵌入能力域的依赖基础 |
| **开放平台应用管理** | 业务对象 | 开发者应用生命周期管理——创建/凭证/成员/能力/版本发布审批 | 消费方入口，通过订阅机制消费能力开放平台的开放能力 |
| **数据开放平台** | 业务对象 | 数据开放通道——数据对象注册、敏感度分级、审批链、API/事件/批量导出/同步服务 | 阶段 2（搁置中），依赖能力开放平台支撑 |

### 1.3 子组件分类

| 分类 | 包含组件 |
|------|---------|
| 开放底座 | 能力开放平台 |
| 消费侧 | 开放平台应用管理 |
| 阶段扩展 | 数据开放平台 |
