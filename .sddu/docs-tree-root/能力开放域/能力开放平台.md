## 1. 业务对象职责

| 属性 | 值 |
|------|-----|
| **对象名称** | 能力开放平台 |
| **所属域** | 能力开放域 |
| **核心职责** | 作为统一的能力开放底座，管理 API/事件/回调三类开放资源的注册、审批上架、消费订阅与权限治理，提供消费网关与 Scope 用户授权 |
| **业务边界** | 不包含数据开放（阶段 2 独立 Feature）；不包含连接器（第四种开放形式独立演进）；不包含能力嵌入（独立 Feature 关联依赖） |

## 2. 属性定义

> 核心业务对象（聚合自 spec §5 技术设计）。

| 属性名 | 类型 | 必填 | 说明 |
|--------|------|:--:|------|
| 分组（Group） | 实体 | ✅ | L1 通用目录结构，支持资源类型（API/事件/回调），配置责任人 |
| 权限（Permission） | 实体 | ✅ | 中文名/英文名/Scope 标识（全局唯一）/认证方式/分组/状态 |
| API 资源 | 实体 | ✅ | 路径（Path）、方法（Method）、接口文档地址、Scope（如 `im:message:get`） |
| 事件资源 | 实体 | ✅ | Topic、事件文档地址、Scope |
| 回调资源 | 实体 | ✅ | 回调文档地址、Scope |
| 审批流（Approval） | 实体 | ✅ | 全局默认 + 场景特有（API/事件/回调），审批人/组、节点顺序 |
| 消费网关 | 组件 | ✅ | API 网关 / 事件网关 / 回调网关 |
| Scope 授权 | 实体 | ✅ | 用户授权管理（OAuth 消费侧） |

## 3. 关联关系

| 关联对象 | 关系类型 | 说明 |
|---------|:------:|------|
| **开放平台应用管理** | 消费方 | 应用通过订阅机制申请/消费 API/事件/回调权限（FR-016~FR-024） |
| **数据开放平台** | 下游依赖 | 数据开放平台由能力开放平台支撑（spec §1.3 定位图） |
| **嵌入能力域** | 关联依赖 | 嵌入能力依赖能力开放平台（CAP-OPEN-001），独立但关联 |
| **连接器平台** | 平行演进 | 第四种开放形式，本版本不与能力开放平台集成 |

## 4. 生命周期

> 开放资源（API/事件/回调）的统一生命周期。

| 状态 | 流转到 | 触发条件 |
|------|--------|---------|
| 草稿 | 待审 | 注册提交（FR-005/009/013） |
| 待审 | 已上架 | 审批通过 |
| 待审 | 已下线 | 审批拒绝或撤回 |
| 已上架 | 已下线 | 删除/下线（FR-007/011/015） |
| 已上架 | 待审（变更） | 核心属性变更需重新审批（FR-006/010/014） |
