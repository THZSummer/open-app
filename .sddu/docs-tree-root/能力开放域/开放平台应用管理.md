## 1. 业务对象职责

| 属性 | 值 |
|------|-----|
| **对象名称** | 开放平台应用管理 |
| **所属域** | 能力开放域 |
| **核心职责** | 为开发者提供完整的应用生命周期管理能力：应用创建与配置、成员协作、能力扩展、版本发布审核，是企业内开发者使用 WeLink 开放平台的核心入口 |
| **业务边界** | 只管理应用侧（消费方）视角；能力本身的注册治理在能力开放平台 |

## 2. 属性定义

> 核心功能模块（聚合自 spec §2 功能需求详情）。

| 属性名 | 类型 | 必填 | 说明 |
|--------|------|:--:|------|
| 应用列表 | 功能 | ✅ | FR-001：当前用户有权限的应用卡片列表，分页（10/20/50）、按修改时间倒序、租户隔离 |
| 应用凭证 | 功能 | ✅ | FR-003：唯一身份凭证信息 |
| 基本信息 | 功能 | ✅ | FR-004：图标（默认列表/自定义上传 128×128 ≤100KB）、中英文名称/描述 |
| 认证方式 | 功能 | ✅ | FR-005：SOAHeader 与 SOAURL 互斥；认证类型 4 种 |
| 成员管理 | 功能 | ✅ | FR-006~009：成员列表/添加/删除/转移 Owner；角色 Owner/管理员/开发者；权限矩阵 |
| 能力列表 | 功能 | ✅ | FR-010：应用已添加能力 |
| 版本发布 | 功能 | ✅ | FR-011~015：版本列表/创建/详情/发布审批/撤回 |
| 应用访问控制 | 功能 | ✅ | FR-016：应用访问控制 |
| 应用类型 | 功能 | ✅ | FR-017：个人应用 vs 业务应用（app_type/app_sub_type） |
| EAMAP 绑定 | 功能 | ✅ | FR-018/020：存量个人应用绑定 EAMAP 升级为业务应用；详情页头部 EAMAP 差异化展示 |
| 操作审计 | 功能 | ✅ | FR-019：覆盖除"新增应用"外所有增删改操作 |

## 3. 关联关系

| 关联对象 | 关系类型 | 说明 |
|---------|:------:|------|
| **能力开放平台** | 消费方 | 应用通过订阅能力开放平台的 API/事件/回调权限实现能力消费 |
| **数据字典 / LookUp** | 配置依赖 | 应用创建表单、成员选择器引用基础配置数据（如默认图标列表） |

## 4. 生命周期

| 状态 | 流转到 | 触发条件 |
|------|--------|---------|
| 创建 | 已创建（草稿） | FR-002 提交创建表单，触发审计 CREATE_APP |
| 编辑 | 已更新 | FR-004 基本信息编辑 |
| 版本发布 | 待审批 | FR-012 创建版本（FR-014 发布审批） |
| 待审批 | 已发布 / 已撤回 | FR-014 审批通过 / FR-015 版本撤回 |
| 有效 | 失效 | 应用下架或访问控制变更 |
