## 1. 业务对象职责

| 属性 | 值 |
|------|-----|
| **对象名称** | 数据字典管理 |
| **所属域** | 基础配置域 |
| **核心职责** | 统一管理系统中的各类属性配置和国际化文本。通过 path 路径实现层级归类，通过 language 字段支持中英文多语言，采用单表扁平结构，便于快速检索和灵活扩展 |
| **业务边界** | 管理属性配置/国际化文本；枚举值和配置项由 LookUp 管理（并行模块） |

## 2. 属性定义

> 核心功能（聚合自 spec §2）。

| 属性名 | 类型 | 必填 | 说明 |
|--------|------|:--:|------|
| 数据字典列表 | 功能 | ✅ | FR-001：编码、名称、路径、描述、语言、状态、创建人/时间、修改人/时间；多条件筛选 |
| 新增数据字典 | 功能 | ✅ | FR-002：编码、名称、路径（可选）、描述（可选）、语言 |
| 编辑数据字典 | 功能 | ✅ | FR-003：修改名称/路径/描述；**编码不可修改** |
| 删除数据字典 | 功能 | ✅ | FR-004：二次确认 |
| 状态变更 | 功能 | ✅ | FR-005：生效↔失效，二次确认 |
| 批量导入 | 功能 | ✅ | FR-006：异步 Excel 导入，任务中心查看进度/结果 |
| 导出 | 功能 | ✅ | FR-007：异步 Excel 导出 |

## 3. 关联关系

| 关联对象 | 关系类型 | 说明 |
|---------|:------:|------|
| **LookUp 管理** | 平行模块 | 同属基础配置域，分管属性文本 vs 枚举配置 |
