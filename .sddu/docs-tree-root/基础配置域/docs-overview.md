## 1. 业务全景

### 1.1 自身概述

| 属性 | 值 |
|------|-----|
| **类型** | 业务域（Domain） |
| **职责描述** | 系统基础数据管理模块——统一管理系统中的属性配置、国际化文本（数据字典）与枚举值/配置项（LookUp），通过标准化管理机制实现业务常量的集中维护和动态配置 |
| **所属业务域** | open-app 开放平台 |
| **版本** | v1.0 |

### 1.2 子组件

| 组件 | 类型 | 描述 | 关系说明 |
|------|------|------|---------|
| **数据字典管理** | 业务对象 | 单表扁平结构，path 层级归类 + language 中英文多语言，支持增删改查、状态切换、Excel 批量导入导出 | 全局配置源 |
| **LookUp 管理** | 业务对象 | 分类 + 项两级结构，统一管理枚举值/配置项，扩展属性 1-6，支持增删改查、状态切换、Excel 导入导出、任务中心 | 全局配置源 |

### 1.3 子组件分类

| 分类 | 包含组件 |
|------|---------|
| 属性/文本配置 | 数据字典管理 |
| 枚举/配置项 | LookUp 管理 |
