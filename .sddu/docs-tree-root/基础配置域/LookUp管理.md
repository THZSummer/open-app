## 1. 业务对象职责

| 属性 | 值 |
|------|-----|
| **对象名称** | LookUp 管理 |
| **所属域** | 基础配置域 |
| **核心职责** | 统一管理业务系统中各类枚举值和配置项。通过标准化的管理机制（分类 + 项两级结构），实现业务常量的集中维护和动态配置 |
| **业务边界** | 管理枚举/配置项；属性配置和国际化文本由数据字典管理（并行模块） |

## 2. 属性定义

> 核心功能（聚合自 spec §2）。

| 属性名 | 类型 | 必填 | 说明 |
|--------|------|:--:|------|
| LookUp 分类管理 | 功能 | ✅ | FR-001~005：分类列表/新增/编辑/删除（级联删除其下项）/状态变更 |
| LookUp 项管理 | 功能 | ✅ | FR-006~011：项列表/新增/编辑/删除/状态变更/详情查看（扩展属性 1-6） |
| 批量导入 | 功能 | ✅ | FR-012：分类及其下所有 LookUp 项异步 Excel 导入 |
| 导出 | 功能 | ✅ | FR-013：异步 Excel 导出 |
| 任务中心 | 功能 | ✅ | FR-014：导入导出任务进度/结果（成功数/失败数/失败明细） |

## 3. 关联关系

| 关联对象 | 关系类型 | 说明 |
|---------|:------:|------|
| **数据字典管理** | 平行模块 | 同属基础配置域，分管枚举配置 vs 属性文本 |
| 任务中心 | 依赖 | Excel 异步导入导出任务进度/结果 |
| 业务模块 | 消费方 | 各业务模块引用 LookUp 枚举值实现动态配置 |
