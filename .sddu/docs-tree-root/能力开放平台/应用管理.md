## 1. 业务概述

| 属性 | 值 |
|------|-----|
| **能力类型** | 平台本身能力 · 基础能力 |
| **对应 Feature** | APP-MGMT-001（开放平台应用管理）+ CAP-OPEN-001（AKSK/成员） |
| **状态** | ✅ validated（能力开放平台）；APP-MGMT-001 spec v6.5 + plan 完成 |
| **业务角色** | 三方应用全生命周期管理，是开放平台一切消费的基础身份 |

**业务说明**：三方平台（业务应用/个人应用/存量个人应用）通过应用管理注册为开放平台消费方，获得凭证（AK/SK）、成员管理、应用版本发布审核等能力。应用是权限、订阅、消费的最小身份单元。

**应用类型**（app_type / app_sub_type）：
- 业务应用（企业应用）— 面向企业内业务系统
- 个人应用 — 面向个人开发者
- 存量个人应用 — 历史数据绑定 eamap 升级为业务应用

## 2. 核心功能

| 功能域 | 功能 | 说明 |
|--------|------|------|
| **应用注册** | 创建应用 | 基本信息（名称/描述/图标）+ 认证方式（SOAHeader/SOAURL 互斥）+ EAMAP 绑定 |
| **应用审核** | 审批流 | 应用创建/变更需平台审批（market-server 待审列表） |
| **凭证管理** | AK/SK | 应用身份（AK/SK）签发与管理，API 消费鉴权基础 |
| **成员管理** | 成员角色 | Owner / 管理员 / 开发者 三角色，权限矩阵化管控 |
| **版本管理** | 应用版本 | 版本创建/编辑/发布/审批/撤回，状态机（待发布/审批中/审批未通过/已发布） |
| **能力关联** | 应用-能力 | 应用绑定能力（app_ability_relation_t），添加后左侧菜单出现对应能力 |
| **操作审计** | 操作日志 | 除"新增应用"外所有增删改操作记录审计日志 |

**成员权限矩阵**（viewer × target）：

| 操作 | Owner | 管理员 | 开发者 |
|------|:----:|:----:|:----:|
| 编辑应用 | ✅ | ✅ | ❌ |
| 删除应用 | ✅ | ❌ | ❌ |
| 添加成员 | ✅ | ✅ | ❌ |
| 删除成员 | ✅ | ✅ | ❌ |
| 转移 Owner | ✅ | ❌ | ❌ |
| 管理版本 | ✅ | ✅ | ✅ |

## 3. 设计真相

### 3.1 相关表

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `app_t` | 应用主表 | app_id, app_name_cn/en, app_type, app_sub_type, status |
| `app_p_t` | 应用属性表 | parent_id → app_t.id, 扩展属性 |
| `app_identity_t` | 应用身份（AK/SK） | app_id, AK/SK 凭证 |
| `app_member_t` | 应用成员 | app_id, account_id, role（Owner/管理员/开发者） |
| `app_version_t` | 应用版本 | app_id, 版本号, 状态 |
| `app_version_p_t` | 版本属性 | parent_id → app_version_t.id |
| `app_ability_relation_t` | 应用-能力关联 | app_id, ability_id（M:N） |
| `eamap_t` | EAMAP 映射 | 存量个人应用绑定 eamap |

### 3.2 相关 API

| 方法 | 路径 | 说明 |
|:----:|------|------|
| POST | /service/open/v2/app | 创建应用 |
| PUT | /service/open/v2/app | 编辑应用 |
| GET | /service/open/v2/app | 应用详情 |
| GET | /service/open/v2/app/list | 应用列表 |
| GET | /service/open/v2/app/identity | 应用身份（AK/SK） |
| POST | /service/open/v2/app/bind-eamap | 绑定 EAMAP |
| GET | /service/open/v2/member/list | 成员列表 |
| POST | /service/open/v2/member | 添加成员 |
| DELETE | /service/open/v2/member | 删除成员 |
| POST | /service/open/v2/member/transfer-owner | 转移 Owner |
| GET | /service/open/v2/version/list | 版本列表 |
| POST | /service/open/v2/version | 创建版本 |
| POST | /service/open/v2/version/publish | 发布版本 |
| POST | /service/open/v2/version/withdraw | 撤回版本 |
| GET | /service/open/v2/apps/pending | 待审应用列表（market-server） |
| POST | /service/open/v2/apps/approval | 应用审批处理（market-server） |

### 3.3 工程映射

| 服务 | 角色 |
|------|------|
| open-server | 应用/成员/版本 CRUD（模块 app/member/version） |
| market-server | 应用审批（模块 approval） |
| wecodesite | 开发者控制台（应用管理页面） |
