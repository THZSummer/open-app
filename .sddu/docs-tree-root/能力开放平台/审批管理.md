## 1. 业务概述

| 属性 | 值 |
|------|-----|
| **能力类型** | 平台本身能力 · 基础能力 |
| **对应 Feature** | CAP-OPEN-001（能力开放平台） |
| **状态** | ✅ validated（全流程完成） |
| **业务角色** | 统一审批底座：动态审批流配置引擎，覆盖 API 注册审批、事件注册审批、回调注册审批、权限申请审批、应用审批 |

**业务说明**（G2）：提供统一的审批管理底座。支持动态审批流配置，覆盖 API 注册审批、事件注册审批、权限申请审批；支持同意、驳回、撤销操作。

**核心机制**：
- **审批流模板**（approval_flow）：可配置的审批流模板（approval-flows CRUD）
- **审批单**（approval_record）：审批实例，记录审批状态与意见
- **审批日志**（approval_log）：审批操作审计
- **多入口**：open-server（资源审批/权限审批）+ market-server（应用审批）

## 2. 核心功能

| 功能域 | 功能 | 说明 |
|--------|------|------|
| **审批流模板** | 模板 CRUD | 审批流模板创建/编辑/删除/查询 |
| **审批执行** | 同意/驳回/撤销 | 审批单处理 |
| **待办查询** | 我的待办 | 当前用户待审批列表 |
| **批量操作** | 批量同意/拒绝 | 批量处理审批单 |
| **催办** | 催办 | 提醒审批人 |
| **应用审批** | 待审应用 | 应用创建/发布审批（market-server） |
| **审批回调** | 结果回调 | 审批结果通知（approvals/callback） |

## 3. 设计真相

### 3.1 相关表

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `v2_approval_flow_t` | 审批流模板 | 流程定义 |
| `v2_approval_record_t` | 审批单 | 审批状态、意见 |
| `v2_approval_log_t` | 审批日志 | record_id → 审批操作审计 |

### 3.2 相关 API

| 方法 | 路径 | 说明 |
|:----:|------|------|
| GET | /service/open/v2/approvals/pending | 我的待办审批 |
| GET | /service/open/v2/approvals/{id} | 审批详情 |
| POST | /service/open/v2/approvals/{id}/approve | 同意 |
| POST | /service/open/v2/approvals/{id}/reject | 拒绝 |
| POST | /service/open/v2/approvals/{id}/cancel | 撤销 |
| POST | /service/open/v2/approvals/batch-approve | 批量同意 |
| POST | /service/open/v2/approvals/batch-reject | 批量拒绝 |
| POST | /service/open/v2/approvals/{id}/urge | 催办 |
| GET | /service/open/v2/approval-flows | 模板列表 |
| POST | /service/open/v2/approval-flows | 创建模板 |
| PUT | /service/open/v2/approval-flows/{id} | 编辑模板 |
| DELETE | /service/open/v2/approval-flows/{id} | 删除模板 |
| GET | /service/open/v2/apps/pending | 待审应用列表（market-server） |
| POST | /service/open/v2/apps/approval | 应用审批处理（market-server） |
| POST | /api/v1/approvals/callback | 审批结果回调（api-server） |

### 3.3 工程映射

| 服务 | 角色 |

| market-server | 应用审批（模块 approval） |
