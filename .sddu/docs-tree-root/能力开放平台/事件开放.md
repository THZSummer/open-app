## 1. 业务概述

| 属性 | 值 |
|------|-----|
| **能力类型** | 连接能力 · 公共连接能力（R2） |
| **对应 Feature** | CAP-OPEN-001（能力开放平台） |
| **状态** | ✅ validated（全流程完成） |
| **业务角色** | 三方平台订阅 XXX 通讯系统的消息事件（收到消息、消息撤回、会议开始等），通过 event-server 网关实时推送 |

**业务说明**（G4）：支持事件的**注册、订阅、取消订阅**、分组、分类；事件消费区分通道类型（企业内部消息队列/WebHook），区分认证类型（应用类 A/B）；支持按应用隔离消费。

**消费链路**：`事件源 → event-server 网关（/gateway/events/publish）→ 基于订阅关系分发 → SSE/WebSocket/内部消息 → 三方应用`

**通道类型**：SSE（text/event-stream）、WebSocket、内部消息队列、WebHook。

## 2. 核心功能

| 功能域 | 功能 | 说明 |
|--------|------|------|
| **事件管理** | 注册/编辑/删除/撤回 | 事件资源生命周期管理（open-server） |
| **事件订阅** | 订阅/撤回/取消 | 应用订阅事件权限 |
| **通道配置** | 事件通道 | 配置消费通道类型/地址/认证 |
| **事件网关** | publish | 发布事件 → 按订阅推送订阅方 |
| **SSE 通道** | 长连接 | /sse/connect/{connectionId} 实时推送 |
| **WebSocket 通道** | 长连接 | /ws 双向通道 |

## 3. 设计真相

### 3.1 相关表

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `v2_event_t` | 事件资源表 | topic, 事件定义 |
| `v2_event_p_t` | 事件属性表 | parent_id → v2_event_t.id |
| `v2_category_t` | 分类表 | 事件分类 |
| `v2_permission_t` | 权限表 | resource_type=EVENT, resource_id → v2_event_t |
| `v2_subscription_t` | 订阅表 | 应用订阅事件权限 |

### 3.2 相关 API

| 方法 | 路径 | 说明 |
|:----:|------|------|
| GET | /service/open/v2/events | 事件列表（管理面） |
| POST | /service/open/v2/events | 注册事件 |
| PUT | /service/open/v2/events/{id} | 编辑事件 |
| DELETE | /service/open/v2/events/{id} | 删除事件 |
| POST | /service/open/v2/events/{id}/withdraw | 撤回事件 |
| GET | /service/open/v2/apps/{appId}/events | 应用已订阅事件 |
| POST | /service/open/v2/apps/{appId}/events/subscribe | 订阅事件 |
| PUT | /service/open/v2/apps/{appId}/events/{id}/config | 配置事件通道 |
| POST | /gateway/events/publish | 发布事件（event-server） |
| GET | /sse/connect/{connectionId} | 建立 SSE 长连接 |
| GET | /ws/count | WebSocket 连接数 |

### 3.3 工程映射

| 服务 | 角色 |
|------|------|
| open-server | 事件资源管理（模块 event）+ 订阅（模块 permission） |
| event-server | 事件网关（publish/SSE/WebSocket/内部消息） |
| wecodesite | 开发者控制台（事件管理/订阅页面） |
