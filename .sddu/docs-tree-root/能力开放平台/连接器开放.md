# 连接器开放

> **文档定位**: sddu-docs-object — 业务对象文档 — 公共连接能力 R4
> **输出文件名**: 连接器开放.md
> **数据来源**: specs-tree-connector-platform (V1/V3) + 代码扫描设计真相
> **创建时间**: 2026-08-03
> **版本**: v1.0 (BIZ-ARCH)

> ⚠️ **业务从属说明**：连接器开放（连接器平台）是能力开放平台**公共连接能力（R4）**，与 API/事件/回调**同级并列的第四种开放形式**（spec 原文）。它是可选项/锦上添花——没有连接器，三方平台也能通过 API/事件/回调达成目标；有了连接器，三方平台可将人工编码的消费场景转化为低代码/零代码配置。

## 1. 业务概述

| 属性 | 值 |
|------|-----|
| **能力类型** | 连接能力 · 公共连接能力（R4）— 第四种开放形式 |
| **对应 Feature** | CONN-PLAT-001（连接器平台 V1）+ CONN-PLAT-003（连接器平台 V3） |
| **状态** | ✅ validated（V1 全流程完成）；✅ validated — completed（V3 全流程完成）；V2 terminated（转入 V3） |
| **业务角色** | 将三方平台原本需要大量人工编码的消费场景转化为低代码/零代码配置（连接器 + 连接流 + 执行引擎） |

**三层架构**（spec §1.2）：

| 层 | 内容 | 类比 |
|----|------|------|
| 📦 外部依赖层 | 连接器 — 纯出站端点定义 | import 的模块/库 |
| 🔀 编排层 | 连接流 — 入口节点→逻辑节点→出口节点 | 函数体 |
| ⚙️ 执行层 | 运行时 — 调度执行引擎 | 虚拟机 |

**节点类型**（V3）：trigger（触发器）/ connector（连接器）/ script（脚本 GraalJS 沙箱）/ parallel（并行）/ exit（出口，数据输出并入 exit）。

## 2. 核心功能

| 功能域 | 功能 | 说明 |
|--------|------|------|
| **连接器管理** | CRUD/版本 | 连接器创建/编辑/失效/恢复、版本发布/调试（open-server） |
| **连接流管理** | CRUD/版本/部署 | 连接流创建/编辑/复制/部署/启动/停止（open-server） |
| **版本管理** | 发布/审批 | 版本发布提交审批、复制草稿、失效/恢复（open-server） |
| **执行引擎** | HTTP 触发 | connector-api /api/v1/flows/{flowId}/invoke 同步执行 |
| **脚本节点** | GraalJS 沙箱 | script 节点执行复杂逻辑（function main(ctx)） |
| **版本调试** | debug | 直接执行指定版本（无需发布/部署） |
| **执行记录** | 记录/步骤 | execution_record + execution_step（V4 表） |

**V3 vs V2 核心变化**：V2（已终止）为"完整好用"（编排画布拖拽、11 条严格类型约束）；V3 转向"简单可用，能兜底"（流程编排表单配置、仅 JSON 语法合法性、脚本节点 GraalJS 沙箱）。

## 3. 设计真相

### 3.1 相关表

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `v2_cp_connector_t` | 连接器表 | 连接器定义 |
| `v2_cp_connector_version_t` | 连接器版本 | connector_id → 1:N |
| `v2_cp_flow_t` | 连接流表 | 连接流定义 |
| `v2_cp_flow_version_t` | 连接流版本 | flow_id → 1:N |
| `v2_cp_connector_version_ref_t` | 编排引用 | flow_version_id / connector_version_id（M:N） |
| `v2_cp_execution_record_t` | 执行记录 | flow_id → N:1 |
| `v2_cp_execution_step_t` | 执行步骤 | execution_id → 1:N, node_type |

### 3.2 相关 API

| 方法 | 路径 | 说明 |
|:----:|------|------|
| POST | /service/open/v2/connectors | 创建连接器（管理面） |
| PUT | /service/open/v2/connectors/{connectorId}/invalidate | 失效连接器 |
| POST | /service/open/v2/connectors/{connectorId}/versions | 创建版本 |
| PUT | /service/open/v2/connectors/{connectorId}/versions/{versionId}/publish | 发布版本 |
| POST | /service/open/v2/flows | 创建连接流（管理面） |
| POST | /service/open/v2/flows/{flowId}/deploy | 部署版本 |
| POST | /service/open/v2/flows/{flowId}/start | 启动 |
| POST | /service/open/v2/flows/{flowId}/stop | 停止 |
| POST | /api/v1/flows/{flowId}/invoke | **HTTP 触发执行**（connector-api） |
| POST | /api/v1/flows/{flowId}/versions/{versionId}/debug | **版本调试**（connector-api） |
| GET | /service/open/v2/executions | 执行记录列表 |
| GET | /service/open/v2/executions/{executionId} | 执行记录详情 |

### 3.3 工程映射

| 服务 | 角色 |
|------|------|
| open-server | 连接器/连接流 CRUD + 版本 + 部署（模块 connector/flow/flowversion/connectorversion） |
| connector-api | 执行引擎（HTTP 触发/调试/GraalJS 脚本/R2DBC） |
| wecodesite | 连接流编排画布（@xyflow/react） |
| wecodesiteDemo | 连接器/流编辑器原型演示 |
