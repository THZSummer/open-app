## 1. 业务概述

| 属性 | 值 |
|------|-----|
| **能力类型** | 连接能力 · 公共连接能力（R3） |
| **对应 Feature** | CAP-OPEN-001（能力开放平台） |
| **状态** | ✅ validated（全流程完成） |
| **业务角色** | XXX 通讯系统主动调用三方平台的 WebHook（审批结果、机器人消息回复、会议录制完成等），实现平台 → 三方的主动回调 |

**业务说明**（G5）：支持回调的**注册、订阅、取消订阅**、分组、分类；支持配置**通道类型（WebHook、SSE、WebSocket 等）**及**认证类型（应用类型凭证 A/B）**；支持按应用隔离消费。

**消费链路**：`平台触发事件 → event-server 网关（/gateway/callbacks/invoke）→ 基于订阅关系调用三方 WebHook`

**回调场景示例**：审批回调、机器人消息回复回调、会议录制完成回调、文件审核回调、表单提交回调。

## 2. 核心功能

| 功能域 | 功能 | 说明 |
|--------|------|------|
| **回调管理** | 注册/编辑/删除/撤回 | 回调资源生命周期管理（open-server） |
| **回调订阅** | 订阅/撤回/取消 | 应用订阅回调权限 |
| **通道配置** | 回调通道 | 配置通道类型（WebHook/SSE/WebSocket）/地址/认证 |
| **回调网关** | invoke | 触发回调 → 调用消费方 WebHook |
| **白名单** | 地址校验 | 回调通道地址白名单控制（ADR-004） |

## 3. 设计真相

### 3.1 相关表

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `v2_callback_t` | 回调资源表 | scope, 回调定义 |
| `v2_callback_p_t` | 回调属性表 | parent_id → v2_callback_t.id |
| `v2_category_t` | 分类表 | 回调分类 |
| `v2_permission_t` | 权限表 | resource_type=CALLBACK, resource_id → v2_callback_t |
| `v2_subscription_t` | 订阅表 | 应用订阅回调权限 |

### 3.2 相关 API

| 方法 | 路径 | 说明 |
|:----:|------|------|
| GET | /service/open/v2/callbacks | 回调列表（管理面） |
| POST | /service/open/v2/callbacks | 注册回调 |
| PUT | /service/open/v2/callbacks/{id} | 编辑回调 |
| DELETE | /service/open/v2/callbacks/{id} | 删除回调 |
| POST | /service/open/v2/callbacks/{id}/withdraw | 撤回回调 |
| GET | /service/open/v2/apps/{appId}/callbacks | 应用已订阅回调 |
| POST | /service/open/v2/apps/{appId}/callbacks/subscribe | 订阅回调 |
| PUT | /service/open/v2/apps/{appId}/callbacks/{id}/config | 配置回调通道 |
| POST | /gateway/callbacks/invoke | 触发回调（event-server） |
| DELETE | /gateway/callbacks/cache/{scope} | 清除订阅缓存 |

### 3.3 工程映射

| 服务 | 角色 |
|------|------|
| open-server | 回调资源管理（模块 callback）+ 订阅（模块 permission） |
| event-server | 回调网关（invoke → 消费方 WebHook） |
| wecodesite | 开发者控制台（回调管理/订阅页面） |
