## 1. 业务概述

| 属性 | 值 |
|------|-----|
| **能力类型** | 基础数据支撑（能力开放平台能力之一） |
| **对应 Feature** | FR-DICTIONARY-001（数据字典管理） |
| **状态** | ✅ planned（规范 + 技术规划完成，待任务分解） |
| **业务角色** | 数据字典管理功能，统一维护业务系统中各类枚举值和配置项，支持中英文多语言 |

**业务说明**（spec §2.2）：数据字典是系统的基础数据管理模块，用于统一管理业务系统中各类枚举值和配置项。通过标准化的管理机制，实现业务常量的集中维护和动态配置。

**核心功能**（spec §2.3）：
- 数据字典 CRUD：编码、名称、路径（层级归类）、语言（中英文多语言）
- 异步批量导入/导出 Excel，任务中心进度跟踪
- 单表扁平结构，灵活扩展

## 2. 核心功能

| 功能域 | 功能 | 说明 |
|--------|------|------|
| **字典 CRUD** | 编码/名称/路径 | 层级归类，中英文多语言 |
| **批量导入** | Excel 导入 | 异步任务，进度跟踪 |
| **批量导出** | Excel 导出 | 异步任务 |
| **任务中心** | 进度跟踪 | 导入/导出任务状态 |

## 3. 设计真相

### 3.1 相关表

| 表名 | 说明 | 关键字段 |

### 3.2 相关 API

| 方法 | 路径 | 说明 |
|:----:|------|------|
| GET | /service/open/v2/dictionary/list | 字典列表 |
| POST | /service/open/v2/dictionary | 新增字典 |
| GET | /service/open/v2/dictionary/{id} | 字典详情 |
| PUT | /service/open/v2/dictionary/{id} | 编辑字典 |
| DELETE | /service/open/v2/dictionary/{id} | 删除字典 |
