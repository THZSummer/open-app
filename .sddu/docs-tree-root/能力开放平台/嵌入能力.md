## 1. 业务概述

| 属性 | 值 |
|------|-----|
| **能力类型** | 平台本身能力 · 基础能力 |
| **对应 Feature** | EMBED-001（狭义嵌入能力） |
| **状态** | 🟡 planned — 平台面 validated / 开放面 builded / API面 tasked（进度 58%） |
| **业务角色** | 特有连接能力（IM 卡片、云盘、邮件等业务模块能力）接入开放平台的基础支撑 |

**业务说明**：XX 通讯平台内部业务模块拥有丰富的特有连接能力（群置顶、群通知、链接增强等），但缺乏标准化的嵌入机制。嵌入能力提供三层架构，让业务模块可以自行注册能力、标准嵌入前端、统一治理。

**三层架构**（spec §1.2）：

| 层面 | 服务 | 核心职责 | 子 Feature | 状态 |
|------|------|---------|-----------|------|
| ① 平台面 | market-server + market-web | ability 类型 CRUD，能力目录管理后台 | EMBED-PLATFORM-001 | ✅ validated |
| ② 开放面 | open-server + wecodesite | ability 查询/订阅、QianKun 微前端嵌入 | EMBED-OPEN-001 | 🔄 builded |
| ③ API面 | api-server | 应用认证、成员查询、权限校验接口 | EMBED-API-001 | 📋 tasked |

**Goals**（spec §1.3）：
- G1 平台管理员在管理后台创建/编辑/排序/删除 ability 类型（平台面）
- G2 能力方注册新的 ability 类型（名称/描述/图标/前端入口URL）（平台面）
- G3 三方应用查询能力目录并订阅 ability（开放面）
- G4 嵌入能力方通过 QianKun 微前端将 UI 嵌入 wecodesite（开放面）
- G5 嵌入能力方可调用 api-server 接口查询用户在应用中的角色（API面）

## 2. 核心功能

| 功能域 | 功能 | 说明 |
|--------|------|------|
| **能力目录** | ability 类型 CRUD | 平台管理员维护能力类型（平台面） |
| **能力注册** | 能力方注册 | 名称/描述/图标/前端入口URL（平台面） |
| **能力订阅** | 查询/订阅 | 三方应用订阅 ability（开放面） |
| **微前端嵌入** | QianKun | 能力方 UI 嵌入 wecodesite（开放面） |
| **角色查询** | 成员角色 | 查询用户在应用中的角色（API面） |
| **能力管理** | admin | 能力管理列表/新增/编辑/删除（market-server） |

## 3. 设计真相

### 3.1 相关表

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `ability_t` | 能力表 | 名称/描述/图标/前端入口URL + V5 新增 6 字段（entry_url/hidden/route_path/alias_name/require_release/load_type） |
| `ability_p_t` | 能力属性表 | parent_id → ability_t.id |
| `app_ability_relation_t` | 应用-能力关联 | app_id, ability_id（M:N） |

### 3.2 相关 API

| 方法 | 路径 | 说明 |
|:----:|------|------|
| GET | /service/open/v2/ability/list | 能力列表（开放面） |
| POST | /service/open/v2/ability | 创建能力 |
| GET | /service/open/v2/ability/subscribed | 已订阅能力 |
| GET | /service/open/v2/ability/admin/list | 能力管理列表（平台面 market-server） |
| POST | /service/open/v2/ability/admin | 新增能力（平台面） |
| PUT | /service/open/v2/ability/admin/{id} | 编辑能力（平台面） |
| DELETE | /service/open/v2/ability/admin/{id} | 删除能力（平台面） |
| POST | /service/open/v2/internal/user/roles | 内部角色同步（API面 api-server） |
