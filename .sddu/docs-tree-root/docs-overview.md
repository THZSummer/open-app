## 3. 技术全景

> 跨域归纳（步骤 5）——从各域 docs-overview.md 技术章节收集。

### 3.1 整体架构

开放平台采用 **单体应用 + 模块化架构**（ADR-001），核心服务集群：

```
wecodesite (React SPA 统一前端)
  ├── market-web         ← 嵌入能力平台面管理后台
  └── open-web 已并入 wecodesite
后端微服务（Java 21 + Spring Boot）：
  ├── open-server        ← 管理面：能力目录/权限/审批/应用管理/连接器 CRUD/嵌入开放面
  ├── connector-api      ← 连接器运行时（执行引擎/调试，WebFlux + R2DBC）
  ├── api-server         ← API 认证鉴权服务（由外向内）
  ├── event-server       ← 事件/回调网关服务（由内向外）
  └── market-server      ← 嵌入能力平台面（ability 目录管理）
数据层：MySQL 5.7（共享）+ Redis 6.0（缓存/令牌桶限流）
```

### 3.2 技术栈概览

| 技术 | 版本 | 用途 |
|------|------|------|
| Java | 21 | 后端语言 |
| Spring Boot | 3.4.6 / 3.5.14 | 后端框架（open-server / connector-api WebFlux） |
| MyBatis | 3.0.4 | ORM |
| React | ^18.2.0 | 前端框架（wecodesite / market-web） |
| Ant Design | 4.x | 前端 UI |
| MySQL | 5.7 | 数据持久化 |
| Redis | 6.0 | 缓存 + 令牌桶限流 |
| GraalJS | 24.1.1 | 脚本节点沙箱执行（连接器 V3） |
| SpringDoc OpenAPI | 2.x | 接口文档 |

### 3.3 部署拓扑

- 各 Spring Boot 服务独立部署，共享同一 MySQL/Redis 实例
- connector-api 为独立运行时服务（V1 起新增），承载连接流同步调度/HTTP 触发/调试
- 前端统一为 wecodesite（open-web 已迁移并入）

### 3.4 跨域数据流

- **能力开放域 → 连接器平台域**：连接器平台「不与能力开放平台集成」（Scope 权限复用 NG18、审批流独立管理 NG19 移至后续）
- **能力开放域 → 嵌入能力域**：嵌入能力依赖能力开放平台（CAP-OPEN-001），独立但关联；开放面消费平台面发布的能力目录
- **基础配置域 → 全局**：数据字典/LookUp 为全局配置数据源，供各业务模块引用
