## 2. 属性定义

> 核心能力（聚合自 spec §1.2 解决方案 + plan 章节）。

| 属性名 | 类型 | 必填 | 说明 |
|--------|------|:--:|------|
| 连接器多版本 | 功能 | ✅ | 草稿→发布→失效→删除；认证扩展数字签名/Cookie/多选组合 |
| 连接流多版本 | 功能 | ✅ | 部署（版本绑定）/启动（状态迁移）/停止（状态迁移）三方解耦 |
| 三级审批 | 功能 | ✅ | 版本发布需三级审批 + 一键催办 |
| 脚本节点 | 功能 | ✅ | GraalJS 沙箱 `function main(ctx)`，复杂逻辑兜底 |
| 编排增强 | 功能 | ✅ | 入站限流（Redis 令牌桶）、超时控制、缓存、并行分支（Flux.merge） |
| 一键复制 | 功能 | ✅ | 连接流复制为独立实体 |
| 运行时监控 | 功能 | ✅ | 运行记录查看、版本配置解析、日志采集 |
| 安全准入 | 功能 | ✅ | URL 白名单、应用维度归属隔离、应用白名单灰度开放 |
| 数据模型 | 功能 | ✅ | JSON Schema input/output、header/query/body；仅校验 JSON 语法合法性 |
