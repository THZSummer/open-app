## 1. 业务对象职责

| 属性 | 值 |
|------|-----|
| **对象名称** | 连接器平台 V1 |
| **所属域** | 连接器平台域 |
| **核心职责** | 验证零代码编排核心价值——连接器（纯出站端点定义）→ 连接流（入口→逻辑→出口节点编排）→ 运行时（调度执行引擎）三层架构 MVP |
| **业务边界** | MVP 仅支持 HTTP 协议；触发器仅 HTTP/手动；无版本管理（编辑即生效）；无审批/Scope 集成 |

## 2. 属性定义

> 核心业务对象（聚合自 spec §5.1）。

| 属性名 | 类型 | 必填 | 说明 |
|--------|------|:--:|------|
| 连接器 | 实体 | ✅ | 名称/图标/描述/类型（HTTP）；连接配置：协议地址、认证方式、入参/出参 Schema、超时、限流 |
| 连接流 | 实体 | ✅ | 名称/描述/状态（运行中/已停止）；编排配置：入口节点、连接器节点、数据映射、出口节点 |
| 运行时 | 组件 | ✅ | 调度引擎、执行上下文、日志（独立部署 connector-api） |
| 执行记录 | 实体 | ✅ | 运行历史查询（监控简化） |
