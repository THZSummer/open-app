## 3. ADR 概述

连接器平台域共 8 条 ADR，全部采纳（ACCEPTED），覆盖三个演进阶段：
- **V1 阶段**（ADR-001~003）：执行引擎、编排画布、独立运行时服务——确立三层架构基础；
- **V3 阶段**（ADR-004~008）：版本快照模型、Redis 令牌桶限流、MySQL 运行记录、引用稽核、透明穿透响应——补齐多版本/安全/运维/调用语义。

注：V2 阶段 ADR-004~007 已随 V2 终止，其决策方向由 V3 承接并演进（V2 的 ADR-004~008 编号在 V3 中重新使用，语义不同）。
