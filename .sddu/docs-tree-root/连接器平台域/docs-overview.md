## 1. 业务全景

### 1.1 自身概述

| 属性 | 值 |
|------|-----|
| **类型** | 业务域（Domain） |
| **职责描述** | 与 API/事件/回调同级并列的第四种开放形式——连接器平台。将三方平台原本需要大量人工编码的消费场景转化为低代码/零代码配置（连接器→连接流→运行时三层架构） |
| **所属业务域** | open-app 开放平台 |
| **版本** | v1.0（域版本：V1 基线 + V3 当前演进） |

### 1.2 子组件

| 组件 | 类型 | 描述 | 关系说明 |
|------|------|------|---------|
| **连接器平台 V1** | 业务对象 | MVP 基线——连接器/连接流 CRUD、同步执行引擎、HTTP 触发、测试执行 | 域基线（validated 100%）；V2/V3 的演进基础 |
| **连接器平台 V2** | 业务对象 | 多版本与增强设计（完整好用方向）——数据处理/错误处理节点、严格类型约束 | 🚫 已终止（terminated），工作转入 V3 |
| **连接器平台 V3** | 业务对象 | 多版本与增强（简单可用方向）——版本管理、三级审批、脚本节点、限流/缓存/并行、安全准入 | 当前演进（validated 100%），基于 V1 基线实现 |

### 1.3 子组件分类

| 分类 | 包含组件 |
|------|---------|
| 有效基线 | 连接器平台 V1、连接器平台 V3 |
| 历史归档 | 连接器平台 V2（terminated） |
